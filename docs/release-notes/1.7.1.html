Kinetic Notes 1.7.1

21 August 2026

A repackaged 1.7

  • The download opens normally again. On some Macs, 1.7 was refused at launch with “Apple could not verify ‘Kinetic Notes.app’ is free of malware”. The application was signed and notarized correctly — the zip around it could damage that signature while being unpacked, before macOS ever looked at it.
  • Two separate faults did it. Stray filesystem metadata was stored inside the application bundle, and unpacking with Finder left some of it behind where no unsigned file is allowed. And four Spanish resource files were sealed under one spelling of their accented names while Finder wrote back another, so they no longer matched the signature.
  • Nothing in the application itself changed. 1.7.1 is 1.7, packaged so that it survives every way of unpacking it, and the release script now refuses to publish an archive with either fault.

If Kinetic Notes is already installed, this was never a problem for you: the updater unpacks releases faithfully, and only a fresh download from the releases page was affected. 1.7.1 installs itself over 1.7 through the usual update check.
