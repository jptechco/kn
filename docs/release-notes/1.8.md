## Line numbers

**Turn on *Show line numbers*** in *Settings → Editing* to number the lines of a note in a gutter beside the text. The numbers are muted, and the line holding the cursor — every line a selection touches — stands out on a faint band. The numbers are drawn beside the text, not added to it: they are never copied, printed or exported. A line that wraps is numbered once.

## A word count

**Turn on *Show word count***, also in *Settings → Editing*, for a bar along the bottom of the window counting the selected note. Click the count or its **^** caret to count something else instead: characters with or without spaces, words, lines or paragraphs. Your choice is remembered.

## What's New, after an automatic update

With *Auto-Update* on, updates install themselves when Kinetic Notes quits, so you never saw what they changed. From now on, the first launch after such an update opens a window with its release notes, once. Updates you install from the update window already show you their notes, so nothing more appears. This begins with the update *after* 1.8, since it is 1.8 that knows how to do it.

## A tidier window

- The divider between the notes and the note is now the same thin line in both layouts, and either layout's divider is dragged by grabbing that line.
- *Show the search field beside the window title* moves to the top of the checkboxes in *Settings → General*.

## Fixes

- **Each layout remembers where you left its divider.** Switching between the stacked and side-by-side layouts used to reset the other layout's divider to an even split.
- **In the side-by-side layout, the lines between notes no longer run through the notes.** They were drawn a little too high, across the end of each preview and its tags.

> **Already running Kinetic Notes 1.6 or later?** 1.8 installs itself through the usual update check. Anyone still on 1.5 or earlier has to install by hand, once, because those versions contain no updater at all.
