Kinetic Notes 1.7

4 August 2026

An Updates pane in Preferences

  • The update controls now have a home of their own, in Settings → Updates: a Check Now button, a Check for Updates Automatically toggle, and an Auto-Update toggle that downloads and installs updates on its own.
  • Auto-Update is available only while automatic checking is on, since a scheduled install has nothing to act on otherwise.
  • The Preferences toolbar is refreshed to match: all five tabs now share one consistent, Dark-Mode-aware icon style.

Dark Mode text, and a Color Scheme override

  • Two Preferences controls that had kept light-only colours — the Fonts & Colors Body Font field and the Notes → Storage file-attribute tables — are legible in Dark Mode again.
  • A new Color Scheme control in Fonts & Colors lets you follow the system appearance (the default) or pin the whole application to Dark or Light. The choice takes effect immediately and is remembered across launches.

Fixes

  • Deleting a note you searched for no longer blanks the list. After typing to narrow the list to one note and deleting it, the remaining notes stayed hidden until an Undo or a relaunch. The stale search is now cleared when a deletion would otherwise empty the list, so the surviving notes come straight back.

1.7 installs itself over 1.6 through the usual update check. Anyone still on 1.5 or earlier has to install by hand, once, because those versions contain no updater at all.
