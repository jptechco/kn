Kinetic Notes 1.6

2 August 2026

The application updates itself

  • A scheduled check no longer interrupts you. When a new version is found on a timer, an Update Available button appears in the toolbar and waits. Click it when you are ready; ignore it if you are not. Choosing Check for Updates… yourself still answers straight away.
  • Every download is verified against a signing key built into the application before it is unpacked. A download that fails that check is discarded, not installed.
  • Nothing is measured. No profile of your system is sent, and no record is kept of who was offered what.

The title bar is stacked again

  • The window's title sits on its own row, with the search field on a full-width row beneath it — the way Notational Velocity had it. macOS 11 had folded the two together; this asks for the older arrangement explicitly.
  • The side-by-side layout is still available, under Settings → General → Show the search field beside the window title.

Also

  • Kinetic Notes is now signed with an Apple Developer ID and notarized, so it opens normally on first launch. The right-click → Open workaround is no longer needed.
  • Hiding and re-showing the toolbar no longer renames the window "Notation".
  • Check for Updates… is translated into every language the application ships.

1.6 is the first version able to receive an update. Anyone running 1.5 or earlier has to install it by hand, once, because those versions contain no updater at all.
