Sparkle

Sparkle 2.9.5 provides the automatic-update mechanism reached from "Check for Updates..."
in the application menu. It ships as Sparkle.framework inside Contents/Frameworks, and it
is the only bundled framework in Kinetic Notes; everything else the application links is
part of macOS. The framework's own Autoupdate helper, Updater.app and XPC services are
inside it and ship with it.

Sparkle is distributed under the MIT license, which is compatible with the GNU General
Public License v3 that covers the rest of the Kinetic Notes source. The external licenses
reproduced beneath Sparkle's own cover code that ships inside the framework: bsdiff and
sais implement binary delta updates, the Ed25519 implementation and SUSignatureVerifier.m
verify the EdDSA signature on every download before it is unpacked.
